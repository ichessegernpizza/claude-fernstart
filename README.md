# Claude Fernstart (Handy-App)

Statische Web-App, mit der ich auf meinem PC `claude remote-control` starte und stoppe.
Die Befehle laufen Ende-zu-Ende verschlüsselt über ntfy.sh. Ohne den Schlüssel vom PC
lässt sich mit dieser Seite nichts steuern. Der Dienst auf dem PC ist nicht Teil dieses Repos.
